Pip & Flicker

アクセシビリティ

最終更新日：2026年10月23日

ゲームもこのウェブサイトも、だれもが楽しめるものにしたいと考えています。このサイトは Web コンテンツ アクセシビリティ ガイドライン（WCAG）2.2 のレベル AA への準拠をめざしています。

このサイトでできること

  • キーボードだけですべて操作でき、いまどこにいるかがいつも見えます。
  • VoiceOver などのスクリーンリーダーで使えます。大切な画像にはすべて説明があります。
  • 端末で動きを減らす設定にしていると、何もひとりでに動きません。動画は勝手に始まらず、エフェクトも止まったままです。どの動画にも一時停止ボタンがあり、上のホタルの動きも止められます。
  • 文字は、画像の上でもしっかりしたコントラストがあります。
  • 200 % まで拡大しても、幅 320 ピクセルの画面でも、横にスクロールせずに読めます。
  • Windows のコントラスト テーマなど、ハイコントラストの色設定でも使えます。
  • Cookie もトラッキングも使わず、ほかの会社のサーバーからは何も読み込みません。

ゲームでは

ゲームには独自のアクセシビリティ設定があります：VoiceOver、オーディオガイド、くっきり表示、文字サイズ、視差効果を減らす、振動。それぞれの説明を見る

わかっている制限

  • 短いゲーム動画には音がありません。それぞれの動画の横の文章で、何が映っているかを説明しています。

確認のしかた

2026年10月23日に、すべてのページを確認しました：キーボードだけでの操作、ブラウザのアクセシビリティツリー、実際の画像の上で測った色のコントラスト、200 % の拡大と幅 320 ピクセル、動きを減らす設定、強制カラー。

困ったことを教えてください

このサイトやゲームで使いにくいところがあれば、support@adrianburcin.com までお知らせください。試したことと、使っている端末を書いてください。いただいたメッセージはすべて読んでいます。

Pip & Flicker

アクセシビリティ

最終更新日：2026年11月6日

ゲームもこのウェブサイトも、だれもが楽しめるものにしたいと考えています。このサイトは Web コンテンツ アクセシビリティ ガイドライン（WCAG）2.2 のレベル AA への準拠をめざしています。

このサイトでできること

  • キーボードだけですべて操作でき、いまどこにいるかがいつも見えます。
  • VoiceOver などのスクリーンリーダーで使えます。大切な画像にはすべて説明があります。
  • 端末で動きを減らす設定にしていると、何もひとりでに動きません。動画は勝手に始まらず、エフェクトも止まったままです。どの動画にも一時停止ボタンがあり、上のホタルの動きも止められます。
  • 文字は、画像の上でもしっかりしたコントラストがあります。
  • 200 % まで拡大しても、幅 320 ピクセルの画面でも、横にスクロールせずに読めます。
  • Windows のコントラスト テーマなど、ハイコントラストの色設定でも使えます。
  • Cookie もトラッキングも使いません。外から読み込むのは Cloudflare の訪問カウンターだけで、Cookie を使わず、あなたがだれかも調べません（[プライバシー](/ja/privacy/#website)）。

アクセシビリティボタン

どのページも左下に、アクセシビリティの人のマークがついた丸いボタンがあります。押すと小さなパネルが開き、次のものを選べます：

  • 文字サイズ： 100 %、125 %、150 %、200 %。
  • コントラストを強く： 文字をより明るく、ふちをはっきりさせ、画像の上の文字のうしろを塗りつぶします。
  • 動きをすべて止める： 動画もホタルも止まります。
  • すべてのリンクに下線。
  • 読みやすい文字： 端末のすっきりした文字にして、行・文字・単語のあいだを広げます。

選んだ設定はこの端末だけに残り、どこにも送られません。リセットでもとに戻ります。パネルはキーボードでも使えます。Esc キーで閉じます。

ゲームでは

ゲームには独自のアクセシビリティ設定があります：VoiceOver、オーディオガイド、くっきり表示、文字サイズ、視差効果を減らす、振動。それぞれの説明を見る

わかっている制限

  • 短いゲーム動画には音がありません。それぞれの動画の横の文章で、何が映っているかを説明しています。
  • アクセシビリティボタンには JavaScript が必要です。JavaScript がなくてもページは使え、ブラウザの拡大や文字の設定も使えます。

確認のしかた

2026年11月5日に、すべてのページをもう一度確認しました：キーボードだけでの操作、見出し・ラベル・リンク・色のコントラストの自動チェック、200 % の文字サイズと幅 320 ピクセル、行・文字・単語のあいだを広げた表示、動きを減らす設定、強制カラー。アクセシビリティボタンの設定もすべて試しました。2026年10月23日には、実際の画像の上で色のコントラストを測りました。

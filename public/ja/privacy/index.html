Pip & Flicker

プライバシーポリシー

最終更新日：2026年11月6日

ひと目でわかる

データの収集なしデベロッパはこのAppからデータを収集しません。

かんたんに言うと： Pip & Flicker は個人情報を集めません。広告も、分析も、トラッキングも、アカウントもありません。ゲームが開発者に何かを送ることはありません。ゲームは自分のサーバーを持たず、サーバーにつなぐこともありません。 このウェブサイトは、Cookie を使わずに訪問の数をかぞえています（下の「このウェブサイトについて」を見てください）。

  • 広告なし、分析なし、トラッキングなし
  • アカウントなし、チャットなし
  • 進行状況はあなたのiPhoneと、あなた自身のiCloudだけに残ります
  • ランキングはAppleのGame Centerを通ります（サインインしているときだけ）
  • 支払いはAppleが行います。わたしたちがあなたの情報を見ることはありません
  • 森からのたよりはiPhoneの中でつくられ、サーバーから届くことはありません

保護者のみなさまへ

ピップはあなたの名前をききません。フリッカーは、あなたがどこにいるかをだれにも言いません。

Pip & Flicker は、子どもをふくむすべての年齢の人のために作られています。子どもをふくめ、だれからも情報を集めません。購入とGame CenterはAppleが扱い、保護者がファミリー共有とスクリーンタイムで決めた設定にしたがいます。

全文

端末に保存されるもの

ゲームは、iPhoneの中のゲーム専用のフォルダに、いくつかの小さなファイルを保存します：

  • 進行状況： 最高距離、シード、仲間となかよし度、強化、図鑑の発見、メダル、毎日の目標、そして森のすべてがアンロック済みかどうか。
  • 設定： 音量、振動、文字サイズ、オーディオガイド、見やすさのオプション、森からのたよりのスイッチ。
  • ゲーム自身のための小さなメモ2つ： 次に流れる曲と、ヘッドホンのヒントを何回出したか。

ゲームは、森からのたよりを届ける時間を決めるために、ほかにも少しだけ覚えています（下の「通知」を見てください）。たとえば、ふだんゲームを開く時間帯や、前回のランの距離です。これらは端末の中と、あなた自身のiCloudにある進行状況のコピーの中に残ります。ほかの端末がこれらを使うことはありません。

BLOOMBURST が起きると、ランのあとで見られるように、ゲームはゲーム画面の写真をとります。その写真はゲームのフォルダに残り、次のランが始まると消えます。

アプリを削除すると、これらはすべて端末から消えます。

最初からやり直す（設定 → その他、2回タップ）を使うと、このiPhoneとiCloudのコピーにある進行状況が消えます。購入と設定は残ります。Game Centerのスコアと実績は、Appleのところにそのまま残ります。

Appleを通るもの

このゲームは、Apple自身のサービスをいくつか使います。それらが扱うものを開発者が受け取ることはなく、見ることもできません。

iCloud（すべての端末で進行状況を引き継ぐ）。 iCloudにサインインしていると、進行状況のコピーがあなただけのiCloudに保存され、新しいiPhoneやほかの端末にも引き継がれます。保存するのはAppleで、あなたのアカウントの中にあります。コピーされるのは進行状況だけで、設定はコピーされません。（Appleのプライバシーポリシー）

Game Center（ランキングと実績）。 Game Centerにサインインしていると、ゲームは最高距離、BLOOMBURST の合計回数、実績の進み具合をAppleのGame Centerに送ります。それらがランキングに表示されます。ゲームのランキング画面には、ほかのプレイヤーのGame Centerのニックネームと写真が表示されます。これらはAppleから届くものです。だれに自分を見せるかをふくめ、Game Centerの設定は iPhoneの設定 → Game Center で変えられます。ランキングでフレンドの一覧を開くと、Game Center のフレンドを表示してよいか iOS がたずねます。この一覧は Apple が管理し、開発者が見ることはありません。答えは iPhone の設定 → Game Center でいつでも変えられます。（Game Centerとプライバシー）

購入（「森を全解放」）。 一度きりのアンロックは App Store で購入します。支払いはAppleが行います。ゲームに伝えられるのは、アンロック済みかどうかだけです。あなたの名前、Apple アカウント、支払い情報をゲームが見ることはありません。保護者は「承認と購入のリクエスト」とスクリーンタイムで、購入を許可したり止めたりできます。（Appleメディアサービスのプライバシー）

写真の共有。 「ラン終了」の画面で「共有」をタップすると、Appleの共有シートで BLOOMBURST の写真を送れます。送り先をあなたが選ばないかぎり、何も送られません。「画像を保存」を選ぶと、iOSが写真ライブラリに写真を加える許可をたずねます。ゲームにできるのは写真を加えることだけです。あなたの写真を見ることはできません。

通知

ゲームから少しだけ「森からのたより」が届くことがあります。多くても1日1回で、最後に遊んでからの1週間で3回までです。その1週間がすぎると止まります。たよりはゲームが端末の中で用意するもので、サーバーから届くことはありません。

はじめは、音を鳴らさず、許可もたずねずに、通知センターに静かに届きます。バナーやロック画面のたよりは、Appleの確認に「許可」と答えたときだけ表示されます。たよりは、ゲームの中（設定 → 森からのたより）か、iPhoneの設定 → 通知 で、いつでもオフにできます。

集めないもの

  • 名前、メールアドレス、年齢、住所、電話番号は集めません
  • 位置情報は集めません
  • 連絡先、カメラ、マイクは使いません
  • 広告識別子はなく、アプリやWebサイトをまたぐトラッキングもしません
  • ゲームには、広告も、分析やクラッシュレポートのサービスもありません
  • アカウントも、ほかのプレイヤーとのチャットもありません
  • あなたの写真を読むこともありません

このウェブサイトについて

このウェブサイトは Cloudflare Web Analytics で訪問の数をかぞえています。何人が来て、どのページが読まれているかを知るためです。Cookie は使わず、あなたがだれかを調べることも、ほかのサイトまで追いかけることもしません。訪問ごとに記録するのは、ページ、どのページから来たか、時間、国、ブラウザと端末の種類だけです。IP アドレスは保存されず、入力したことやタップしたことも記録されません。この数は、このウェブサイトだけのものです。ゲームは何も送りません。ブラウザがカウンターをブロックしても、サイトはそのまま使えます。

変更について

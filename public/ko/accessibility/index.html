손쉬운 사용

최종 업데이트: 2026년 11월 5일

게임도, 이 웹사이트도 누구나 즐길 수 있기를 바라요. 이 사이트는 웹 콘텐츠 접근성 지침(WCAG) 2.2 AA 수준을 목표로 해요.

이 사이트가 하는 일

  • 키보드만으로 모든 것을 쓸 수 있고, 지금 어디에 있는지 늘 보여요.
  • VoiceOver 같은 화면 읽기 프로그램으로 쓸 수 있어요. 중요한 그림에는 모두 설명이 있어요.
  • 기기에서 동작을 줄이도록 설정하면, 저절로 움직이는 것이 없어요. 동영상은 혼자 재생되지 않고 효과도 멈춰 있어요. 모든 동영상에 일시 정지 버튼이 있고, 맨 위의 반딧불이도 멈출 수 있어요.
  • 글자는 그림 위에서도 대비가 뚜렷해요.
  • 200 % 로 확대하거나 너비 320 픽셀 화면에서도 옆으로 스크롤하지 않고 볼 수 있어요.
  • Windows 대비 테마 같은 고대비 색상 설정에서도 잘 작동해요.
  • 쿠키나 추적을 쓰지 않고, 다른 회사의 서버에서 아무것도 불러오지 않아요.

손쉬운 사용 버튼

모든 페이지의 왼쪽 아래에 손쉬운 사용 사람 모양이 그려진 동그란 버튼이 있어요. 누르면 작은 창이 열리고, 이런 걸 고를 수 있어요:

  • 글자 크기: 100 %, 125 %, 150 %, 200 %.
  • 대비 더 강하게: 글자를 더 밝게, 테두리를 더 또렷하게 하고, 그림 위 글자 뒤에는 꽉 찬 배경을 깔아요.
  • 모든 움직임 멈추기: 동영상과 반딧불이가 멈춰요.
  • 모든 링크에 밑줄.
  • 읽기 쉬운 글자: 기기의 깔끔한 글꼴로 바꾸고, 줄과 글자와 단어 사이를 더 넓혀요.

고른 설정은 이 기기에만 남고 어디에도 보내지 않아요. 초기화를 누르면 모두 처음대로 돌아가요. 창은 키보드로도 쓸 수 있어요: Esc 키로 닫혀요.

게임에는 자체 손쉬운 사용 설정이 있어요: VoiceOver, 오디오 가이드, 잘 보이게, 글자 크기, 동작 줄이기, 진동. 각각 무엇을 하는지 보기

알려진 한계

  • 짧은 게임 동영상에는 소리가 없어요. 동영상마다 옆의 글이 무엇을 보여 주는지 알려 줘요.
  • 손쉬운 사용 버튼은 JavaScript가 있어야 해요. JavaScript가 없어도 페이지는 잘 작동하고, 브라우저의 확대와 글자 설정도 그대로 쓸 수 있어요.

이렇게 확인했어요

2026년 11월 5일, 모든 페이지를 다시 확인했어요: 키보드만으로, 제목·이름표·링크·색상 대비의 자동 검사로, 200 % 글자 크기와 너비 320 픽셀에서, 줄과 글자와 단어 사이를 넓힌 상태에서, 동작 줄이기와 강제 색상에서요. 손쉬운 사용 버튼의 설정도 하나하나 모두 써 봤어요. 2026년 10월 23일에는 실제 그림 위에서 색상 대비를 쟀어요.
